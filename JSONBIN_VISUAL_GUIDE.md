# JSONBin.io Visual Guide - Name Kahan Likhein?

## 🎯 Simple Answer:

### **JSONBin.io Dashboard Par:**

1. **Login** karo: https://jsonbin.io/
2. Dashboard par **"Create Bin"** button dikhega
3. Click karo
4. Ek form khulega jismein:

```
┌──────────────────────────────────────┐
│  Create New Bin                      │
├──────────────────────────────────────┤
│                                      │
│  Bin Name: [Type here: SM_LUXE...]  │ ← YAHAN NAME LIKHO
│                                      │
│  Data: [Type here: [] ]              │ ← YAHAN [] LIKHO
│                                      │
│  [Create Bin]  [Cancel]              │
└──────────────────────────────────────┘
```

---

## 📝 Exact Steps:

### **Step 1: Create Bin Button**
- Dashboard par **"Create Bin"** ya **"New Bin"** button click karo

### **Step 2: Form Fill Karo**
- **"Bin Name"** field mein: `SM_LUXE_PRODUCTS` likho
- **"Data"** field mein: `[]` likho (empty array)
- **"Create"** ya **"Create Bin"** button click karo

### **Step 3: Bin ID Lein**
- Bin create hone ke baad
- URL mein Bin ID dikhega
- Ya bin details page par Bin ID dikhega
- Copy karo

### **Step 4: API Key Lein**
- Top right corner → **Account Settings**
- **"API Keys"** section
- **"Master Key"** copy karo

---

## ⚠️ Important Notes:

- **Name field optional hai** - agar nahi dikha to data field se bhi kaam chalega
- **Data field mein `[]` zaroor likho** (empty array)
- **Bin ID** URL se bhi mil sakta hai
- **API Key** account settings se milta hai

---

## 🔧 Agar Name Field Nahi Dikha:

1. Data field mein `[]` likho
2. Create click karo
3. Bin create hone ke baad rename kar sakte ho

---

**Yeh simple hai - just "Create Bin" click karo aur form fill karo!**
